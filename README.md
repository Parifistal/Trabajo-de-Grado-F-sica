# Anexos del Trabajo de Grado: Sistema Autónomo Fotovoltaico (SAF)

Repositorio de soporte que contiene los datos experimentales, scripts de procesamiento y códigos de visualización utilizados en el trabajo de grado:
* **Autor:** German Stevan Rubiano Socha[cite: 1]
* **Director:** Nelson Libardo Forero Chacón[cite: 1]
* **Codirector:** Miguel Ángel Delgado Gómez[cite: 1]
* **Institución:** Universidad Distrital Francisco José de Caldas - Grupo FMAES[cite: 1]

## Contenido del Repositorio
- `data/`: Contiene los archivos con registros de irradiancia, voltajes de módulos PV y baterías (formatos `.dat`).
- `scripts/python/`: Rutinas desarrolladas para el tratamiento de datos y cálculos energéticos.
- `scripts/gnuplot/`: Archivos `.gp` automatizados para la generación de curvas características y perfiles diarios.
- `outputs/`: Gráficas en alta resolución presentadas en el documento de tesis.
